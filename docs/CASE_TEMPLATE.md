# Plantilla de caso verificable (STAR/CAR)

La [matriz de cargos](../PROFESIONAL_ROLES.md) distingue entre experiencia probada y habilidad transferible. Un caso bien documentado es lo que convierte una en la otra. Cada caso publicado debe poder verificarse: enlace a un repositorio, release, issue, PR o documento.

**Regla:** no se publica nada que no sea cierto ni verificable. Si una cifra es una estimación, se dice. Si no hubo responsabilidad formal sobre personas o presupuesto, se dice.

## Caso: _título corto_

| Campo | Contenido |
|---|---|
| **Cargo al que apunta** | p. ej. Business Analyst, Project Coordinator, Pre-sales |
| **Contexto** | Organización o proyecto, año, tamaño, problema inicial |
| **Mi responsabilidad** | Qué decidí o entregué yo; qué hicieron otros |
| **Alcance formal** | Personas a cargo: ninguna / n · Presupuesto: ninguno / monto · Proveedores o clientes |
| **Decisión clave** | La decisión difícil y las alternativas descartadas |
| **Acciones** | 3–5 pasos concretos |
| **Resultado medible** | Tiempo, calidad, riesgo, costo, adopción o ingreso, con cifra y fuente |
| **Límites** | Lo que este caso **no** demuestra |
| **Evidencia** | Enlaces a repositorio, release, issue, PR o documento |
