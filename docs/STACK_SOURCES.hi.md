इस प्रोफ़ाइल का टेक्नोलॉजी स्टैक उस पर आधारित है जो इस खाते के सार्वजनिक रिपॉज़िटरी में वास्तव में मौजूद है, इरादों की सूची पर नहीं। यह दस्तावेज़ बताता है कि प्रमाण क्या माना जाता है, हर क्षेत्र किस रिपॉज़िटरी या स्थान से आता है, और क्या केवल लेखक की घोषणा है।

## शामिल करने के नियम

1. **केवल अपने सार्वजनिक रिपॉज़िटरी।** निजी रिपॉज़िटरी और तीसरे पक्ष के प्रोजेक्ट के फ़ोर्क नहीं गिने जाते।
2. **प्रमाण रिपॉज़िटरी में है।** जो कोड, मैनिफ़ेस्ट और लॉकफ़ाइल, Docker/Compose, CI/CD वर्कफ़्लो, Terraform, या किसी प्रयोगशाला या पाठ्यक्रम के दस्तावेज़ में दिखता है, वही गिना जाता है। पाठ्यक्रम के पाठ में सरसरी उल्लेख नहीं गिना जाता: Snowflake, BigQuery, Spark या Airflow केवल पाठ्यक्रम-सामग्री के रूप में आते हैं, इसलिए स्टैक में नहीं हैं।
3. **उपयोग, वर्ष नहीं।** रिपॉज़िटरी में दिखना उपयोग का प्रमाण है, उत्पादक अनुभव के वर्षों का दावा नहीं।
4. **घोषित बातें अलग रखी जाती हैं।** जो सार्वजनिक रिपॉज़िटरी से जाँचा नहीं जा सकता, उसे लेखक द्वारा घोषित के रूप में चिह्नित किया जाता है (नीचे)।

## लेखक द्वारा घोषित (सार्वजनिक रिपॉज़िटरी में सत्यापित नहीं)

ये बातें स्टैक में इसलिए हैं कि लेखक इनका उपयोग करता है, पर कोई सार्वजनिक रिपॉज़िटरी अकेले इन्हें सिद्ध नहीं करता:

- **Cloudflare** — व्यक्तिगत कार्य।
- **ChatGPT Plus** (2023 से), **Antigravity** और **OpenCode** — AI-सहायता वाले विकास प्रवाह के उपकरण।
- **GitLab से जुड़ी संचालित वेबसाइटों पर AWS** — सार्वजनिक रूप से जो सत्यापित हो सकता है वह प्रोजेक्ट [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab) है, वे वेबसाइटें नहीं।

## कैसे जाँचें

कोई भी GitHub CLI (`gh`) से यही जाँच दोहरा सकता है:

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## इसे कैसे बनाए रखा जाता है

- तकनीकें और उनका ग्राफ़िक `scripts/stack_data.json` से `scripts/stack_graphic.py` द्वारा बनते हैं; प्रोफ़ाइल के आँकड़े `stats.yml` वर्कफ़्लो गिनता है।
- कोई तकनीक तब स्टैक में आती है जब वह किसी सार्वजनिक रिपॉज़िटरी (कोड, मैनिफ़ेस्ट, वर्कफ़्लो या प्रयोगशाला) में दिखती है, और तब हटती है जब वह कहीं नहीं दिखती।

## सीमाएँ

- GitHub की भाषा-सांख्यिकी जनरेट की गई और डेटा फ़ाइलें भी गिनती है (इसीलिए HTML इतना भारी दिखता है): यह बताती है कि रिपॉज़िटरी में क्या है, यह नहीं कि मैं हर भाषा कितनी अच्छी तरह जानता हूँ।
- निजी रिपॉज़िटरी और ग्राहकों के लिए किया गया कार्य इस स्टैक का हिस्सा नहीं हैं और प्रमाण के रूप में उपयोग नहीं होते।
