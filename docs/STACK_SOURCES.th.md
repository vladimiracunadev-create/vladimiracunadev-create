สแตกเทคโนโลยีของโปรไฟล์นี้มาจากสิ่งที่มีอยู่จริงในที่เก็บสาธารณะของบัญชีนี้ ไม่ใช่รายการความตั้งใจ เอกสารนี้อธิบายว่าอะไรนับเป็นหลักฐาน แต่ละด้านมาจากที่เก็บหรือแหล่งใด และอะไรเป็นเพียงคำแถลงของผู้เขียน

## กฎการรวมเข้าสแตก

1. **เฉพาะที่เก็บสาธารณะของตนเอง** ที่เก็บส่วนตัวและ fork ของโครงการบุคคลที่สามไม่นับ
2. **หลักฐานอยู่ในที่เก็บ** สิ่งที่นับคือสิ่งที่ปรากฏในโค้ด manifest และ lockfile, Docker/Compose, เวิร์กโฟลว์ CI/CD, Terraform หรือเอกสารของห้องทดลองหรือหลักสูตร การกล่าวถึงผ่าน ๆ ในเนื้อหาหลักสูตรไม่นับ: Snowflake, BigQuery, Spark และ Airflow ปรากฏเป็นเนื้อหาหลักสูตรเท่านั้น จึงไม่อยู่ในสแตก
3. **ดูการใช้งาน ไม่ใช่จำนวนปี** การปรากฏในที่เก็บเป็นหลักฐานว่าใช้งาน ไม่ใช่การยืนยันจำนวนปีประสบการณ์ในการผลิตจริง
4. **สิ่งที่แถลงไว้แยกต่างหาก** สิ่งที่ตรวจสอบจากที่เก็บสาธารณะไม่ได้จะระบุว่าเป็นคำแถลงของผู้เขียน (ด้านล่าง)

## ผู้เขียนแถลงไว้ (ตรวจสอบจากที่เก็บสาธารณะไม่ได้)

รายการเหล่านี้อยู่ในสแตกเพราะผู้เขียนใช้งาน แต่ไม่มีที่เก็บสาธารณะใดพิสูจน์ได้ด้วยตัวเอง:

- **Cloudflare** — งานส่วนตัว
- **ChatGPT Plus** (ตั้งแต่ปี 2023), **Antigravity** และ **OpenCode** — เครื่องมือในกระบวนการพัฒนาที่มี AI ช่วย
- **AWS ในเว็บไซต์ที่ใช้งานจริงที่เชื่อมกับ GitLab** — สิ่งที่ตรวจสอบได้สาธารณะคือโครงการ [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab) ไม่ใช่เว็บไซต์เหล่านั้น

## วิธีตรวจสอบ

ใครก็ตรวจสอบซ้ำได้ด้วย GitHub CLI (`gh`):

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## วิธีดูแลรักษา

- เทคโนโลยีและกราฟิกสร้างจาก `scripts/stack_data.json` ด้วย `scripts/stack_graphic.py` ส่วนตัวเลขของโปรไฟล์คำนวณโดยเวิร์กโฟลว์ `stats.yml`
- เทคโนโลยีเข้าสู่สแตกเมื่อปรากฏในที่เก็บสาธารณะ (โค้ด manifest เวิร์กโฟลว์ หรือห้องทดลอง) และออกเมื่อไม่ปรากฏที่ใดอีก

## ข้อจำกัด

- สถิติภาษาของ GitHub นับไฟล์ที่สร้างขึ้นและไฟล์ข้อมูลด้วย (HTML จึงมีสัดส่วนมาก) บอกได้ว่าที่เก็บมีอะไร ไม่ได้บอกว่าผมเชี่ยวชาญแต่ละภาษาแค่ไหน
- ที่เก็บส่วนตัวและงานของลูกค้าไม่เป็นส่วนของสแตกนี้ และไม่ใช้เป็นหลักฐาน
