Το τεχνολογικό stack του προφίλ προέρχεται από ό,τι υπάρχει στα δημόσια αποθετήρια αυτού του λογαριασμού, όχι από μια λίστα προθέσεων. Το έγγραφο εξηγεί τι λογίζεται ως τεκμήριο, από ποιο αποθετήριο ή χώρο προέρχεται κάθε τομέας και τι είναι απλώς δήλωση του συγγραφέα.

## Κανόνες συμπερίληψης

1. **Μόνο δικά μου δημόσια αποθετήρια.** Τα ιδιωτικά αποθετήρια και τα forks έργων τρίτων δεν μετρούν.
2. **Το τεκμήριο βρίσκεται στο αποθετήριο.** Μετρά ό,τι εμφανίζεται σε κώδικα, manifest και lockfile, Docker/Compose, workflows CI/CD, Terraform ή στην τεκμηρίωση ενός εργαστηρίου ή προγράμματος σπουδών. Μια περαστική αναφορά στο κείμενο ενός μαθήματος δεν μετρά: τα Snowflake, BigQuery, Spark ή Airflow εμφανίζονται μόνο ως περιεχόμενο μαθημάτων και γι' αυτό δεν υπάρχουν στο stack.
3. **Χρήση, όχι έτη.** Η εμφάνιση σε αποθετήριο είναι τεκμήριο χρήσης, όχι ισχυρισμός ετών παραγωγικής εμπειρίας.
4. **Τα δηλωμένα μένουν χωριστά.** Ό,τι δεν επαληθεύεται από δημόσια αποθετήρια επισημαίνεται ως δηλωμένο από τον συγγραφέα (παρακάτω).

## Δηλωμένα από τον συγγραφέα (μη επαληθεύσιμα σε δημόσια αποθετήρια)

Αυτά τα στοιχεία υπάρχουν στο stack επειδή ο συγγραφέας τα χρησιμοποιεί, αλλά κανένα δημόσιο αποθετήριο δεν τα αποδεικνύει από μόνο του:

- **Cloudflare** — προσωπική εργασία.
- **ChatGPT Plus** (από το 2023), **Antigravity** και **OpenCode** — εργαλεία της ροής ανάπτυξης με υποστήριξη AI.
- **AWS σε λειτουργικούς ιστότοπους συνδεδεμένους με το GitLab** — δημόσια επαληθεύσιμο είναι το έργο [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab), όχι οι ιστότοποι αυτοί.

## Πώς να το ελέγξετε

Οποιοσδήποτε μπορεί να επαναλάβει τον έλεγχο με το GitHub CLI (`gh`):

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## Πώς διατηρείται

- Οι τεχνολογίες και το γράφημά τους παράγονται από το `scripts/stack_data.json` με το `scripts/stack_graphic.py`· τα νούμερα του προφίλ τα υπολογίζει το workflow `stats.yml`.
- Μια τεχνολογία μπαίνει στο stack όταν εμφανίζεται σε δημόσιο αποθετήριο (κώδικας, manifest, workflow ή εργαστήριο) και βγαίνει αν δεν εμφανίζεται πια πουθενά.

## Όρια

- Τα στατιστικά γλωσσών του GitHub μετρούν και παραγόμενα αρχεία και αρχεία δεδομένων (γι' αυτό το HTML βαραίνει τόσο): δείχνουν τι περιέχει ένα αποθετήριο, όχι πόσο καλά γνωρίζω κάθε γλώσσα.
- Τα ιδιωτικά αποθετήρια και η εργασία για πελάτες δεν ανήκουν σε αυτό το stack και δεν χρησιμοποιούνται ως τεκμήριο.
