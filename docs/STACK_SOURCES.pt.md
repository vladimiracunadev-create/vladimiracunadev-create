O Stack tecnológico do perfil sai do que existe nos repositórios públicos desta conta, não de uma lista de intenções. Este documento explica o que conta como evidência, de qual repositório ou lugar sai cada área e o que é apenas uma declaração do autor.

## Regras de inclusão

1. **Somente repositórios públicos próprios.** Não contam os repositórios privados nem os forks de projetos de terceiros.
2. **A evidência está no repositório.** Conta o que aparece em código, manifestos e lockfiles, Docker/Compose, workflows de CI/CD, Terraform ou na documentação de um laboratório ou currículo. Uma menção solta no texto de um curso não conta: Snowflake, BigQuery, Spark ou Airflow aparecem apenas como conteúdo de cursos e por isso não constam no Stack.
3. **Uso, não anos.** Aparecer em um repositório é evidência de uso, não uma afirmação de anos de experiência produtiva.
4. **O declarado fica à parte.** O que não pode ser comprovado a partir de repositórios públicos é marcado como declarado pelo autor (abaixo).

## Declarado pelo autor (não verificável em repositórios públicos)

Estas peças estão no Stack porque o autor as usa, mas nenhum repositório público as comprova por si só:

- **Cloudflare** — trabalho pessoal.
- **ChatGPT Plus** (desde 2023), **Antigravity** e **OpenCode** — ferramentas do fluxo de desenvolvimento assistido por IA.
- **AWS em sites operacionais associados ao GitLab** — o que se pode verificar em público é o projeto [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab), não esses sites.

## Como verificar

Qualquer pessoa pode repetir a verificação com a CLI do GitHub (`gh`):

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## Como é mantido

- As tecnologias e o gráfico são gerados a partir de `scripts/stack_data.json` com `scripts/stack_graphic.py`; os números do perfil são calculados pelo workflow `stats.yml`.
- Uma tecnologia entra no Stack quando aparece em um repositório público (código, manifesto, workflow ou laboratório) e sai se deixar de aparecer em todos.

## Limites

- As estatísticas de linguagens do GitHub contam arquivos gerados e de dados (por isso o HTML pesa tanto): servem para saber o que há em um repositório, não o quanto conheço cada linguagem.
- Os repositórios privados e o trabalho para clientes não fazem parte deste Stack nem são usados como evidência.
