Stack teknologi pada profil ini berasal dari apa yang ada di repositori publik akun ini, bukan dari daftar niat. Dokumen ini menjelaskan apa yang dihitung sebagai bukti, dari repositori atau tempat mana tiap area berasal, dan apa yang hanya pernyataan penulis.

## Aturan penyertaan

1. **Hanya repositori publik milik sendiri.** Repositori privat dan fork proyek pihak ketiga tidak dihitung.
2. **Bukti ada di repositori.** Yang dihitung adalah yang muncul dalam kode, manifes dan lockfile, Docker/Compose, workflow CI/CD, Terraform, atau dokumentasi laboratorium atau kurikulum. Sekadar sebutan di teks kursus tidak dihitung: Snowflake, BigQuery, Spark atau Airflow hanya muncul sebagai isi kursus sehingga tidak masuk Stack.
3. **Penggunaan, bukan tahun.** Muncul di repositori adalah bukti penggunaan, bukan klaim tahun pengalaman produktif.
4. **Yang dinyatakan dipisahkan.** Apa yang tidak dapat diperiksa dari repositori publik ditandai sebagai dinyatakan oleh penulis (di bawah).

## Dinyatakan oleh penulis (tidak dapat diverifikasi di repositori publik)

Bagian ini ada di Stack karena penulis menggunakannya, tetapi tidak ada repositori publik yang membuktikannya sendiri:

- **Cloudflare** — pekerjaan pribadi.
- **ChatGPT Plus** (sejak 2023), **Antigravity** dan **OpenCode** — alat alur pengembangan berbantuan AI.
- **AWS pada situs operasional yang terkait GitLab** — yang dapat diverifikasi secara publik adalah proyek [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab), bukan situs-situs itu.

## Cara memeriksanya

Siapa pun dapat mengulangi pemeriksaan dengan CLI GitHub (`gh`):

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## Cara pemeliharaannya

- Teknologi dan grafiknya dihasilkan dari `scripts/stack_data.json` dengan `scripts/stack_graphic.py`; angka profil dihitung oleh workflow `stats.yml`.
- Sebuah teknologi masuk ke Stack ketika muncul di repositori publik (kode, manifes, workflow atau laboratorium) dan keluar jika tidak lagi muncul di mana pun.

## Batasan

- Statistik bahasa GitHub menghitung berkas buatan dan data (karena itu HTML begitu besar): berguna untuk mengetahui isi repositori, bukan seberapa baik saya menguasai tiap bahasa.
- Repositori privat dan pekerjaan untuk klien bukan bagian dari Stack ini dan tidak dipakai sebagai bukti.
