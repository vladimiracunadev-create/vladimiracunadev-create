이 프로필의 기술 스택은 의도 목록이 아니라 이 계정의 공개 저장소에 실제로 있는 것에서 나옵니다. 이 문서는 무엇이 증거로 인정되는지, 각 영역이 어떤 저장소나 장소에서 나오는지, 그리고 무엇이 저자의 선언에 불과한지 설명합니다.

## 포함 규칙

1. **본인 소유의 공개 저장소만.** 비공개 저장소와 제3자 프로젝트의 포크는 포함하지 않습니다.
2. **증거는 저장소 안에 있습니다.** 코드, 매니페스트와 락파일, Docker/Compose, CI/CD 워크플로, Terraform, 또는 실습실·커리큘럼 문서에 나타나는 것을 인정합니다. 강의 본문의 단순 언급은 인정하지 않습니다. Snowflake, BigQuery, Spark, Airflow는 강의 내용으로만 등장하므로 스택에 없습니다.
3. **연수가 아니라 사용.** 저장소에 나타난다는 것은 사용의 증거이지 실무 경력 연수에 대한 주장이 아닙니다.
4. **선언한 것은 따로 표시합니다.** 공개 저장소로 확인할 수 없는 것은 저자의 선언으로 표시합니다(아래).

## 저자가 선언한 것(공개 저장소에서 확인할 수 없음)

아래 항목은 저자가 사용하기 때문에 스택에 있지만, 공개 저장소 하나만으로는 입증되지 않습니다.

- **Cloudflare** — 개인 작업.
- **ChatGPT Plus**(2023년부터), **Antigravity**, **OpenCode** — AI 지원 개발 흐름의 도구.
- **GitLab과 연관된 운영 웹사이트의 AWS** — 공개적으로 확인 가능한 것은 프로젝트 [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab)이며 해당 웹사이트가 아닙니다.

## 확인하는 방법

누구나 GitHub CLI(`gh`)로 같은 확인을 반복할 수 있습니다.

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## 유지 방식

- 기술과 그래프는 `scripts/stack_data.json`에서 `scripts/stack_graphic.py`로 생성되며, 프로필의 수치는 `stats.yml` 워크플로가 계산합니다.
- 기술은 공개 저장소(코드, 매니페스트, 워크플로, 실습실)에 나타나면 스택에 들어오고, 어디에도 나타나지 않게 되면 빠집니다.

## 한계

- GitHub 언어 통계는 생성 파일과 데이터 파일도 센다(그래서 HTML 비중이 큼). 저장소에 무엇이 있는지 보여줄 뿐 각 언어를 얼마나 잘 아는지를 뜻하지 않습니다.
- 비공개 저장소와 고객 작업은 이 스택에 포함되지 않으며 증거로도 쓰지 않습니다.
