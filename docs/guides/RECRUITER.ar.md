## في سطر واحد

مهندس حلول وSenior Full-Stack بخبرة تفوق 16 عامًا، تكوَّن في هندسة المعلوماتية والحوسبة **وفي** إدارة الأعمال: يربط الأعمال بالتقنية ويسلّم بأدلة قابلة للتحقق.

## هل أناسب الوظيفة؟

| إذا كانت الوظيفة تطلب… | إجابة صريحة |
|---|---|
| مهندس حلول، Tech Lead، Senior Full-Stack | ✅ مسيرة تقنية مثبتة (أكثر من 16 عامًا) |
| تحديث الأنظمة القديمة (مثل PHP 5.x → 8.x) | ✅ تطوير تدريجي دون إيقاف التشغيل |
| الأتمتة والذكاء الاصطناعي (n8n وLangGraph وMCP ووكلاء بضوابط حماية) | ✅ منتجات ومختبرات عامة يمكن تشغيلها |
| DevOps وCI/CD والسحابة وSRE للتطبيقات | ⚙️ نطاق مكمِّل بأدلة في المستودعات؛ دون مناوبات مؤسسية مثبتة |
| تحليل الأعمال وإدارة مشاريع تقنية المعلومات والمنتج وما قبل البيع | 🔁 كفاءة قابلة للنقل أو إمكانية تقديم، بحسب النطاق |
| الإدارة أو القيادة (مدير تقنية المعلومات وCIO وHead of IT) | 🎯 هدف تطوير مستقبلي: الفريق والميزانية والنتائج ما زالت بحاجة إلى إثبات |

التصنيف الكامل (خبرة مثبتة، كفاءة قابلة للنقل، إمكانية تقديم، هدف مستقبلي) موجود في [Role matrix](../../PROFESIONAL_ROLES.md) وفي [فرص العمل في مجالات الإدارة والإدارة وغير الترميز](../MANAGEMENT.ar.md).

## معلومات سريعة

- **الحزمة الرئيسية:** PHP 8 · Python · Rust · Go · Node/TS · Java 21 · .NET 8 · Dart/Flutter · AWS · Terraform · Kubernetes · Docker · n8n · LangGraph/MCP. التفاصيل حسب المجال في [المكدس التقني](../../README.ar.md#-المكدس-التقني).
- **النمط:** عن بُعد أو هجين بحسب المشروع.
- **السيرة الذاتية:** يوفّر [الملف التعريفي للأعمال](https://vladimiracunadev-create.github.io/) ملفات PDF بـ22 لغة.

## تحقّق في 5 دقائق

1. اقرأ [الحالة التي يمكن التحقق منها](../../README.ar.md#الحالة-التي-يمكن-التحقق-منها): أرقام مع مصادرها.
2. افتح منتجًا قابلًا للتثبيت من [عرض المنظومة كاملة](../ECOSYSTEM.ar.md) وتحقق من إصداره وقيم التحقق والاختبارات.
3. افتح أي مستودع: كلٌّ منها يذكر حالته (`يعمل` أو `موثَّق/SCAFFOLD` أو `مخطَّط`) وما **لا** يفعله.

## ما لا يدّعيه هذا الملف

- المشاريع الخاصة والمختبرات **لا** تُعرض كخبرة عمل في شركات.
- لا توجد شهادات مهنية معلنة (مثل PMP وCISA وISO 27001).
- قيادة الأشخاص والميزانية والموردين داخل مؤسسة لم تُثبت بعد.
