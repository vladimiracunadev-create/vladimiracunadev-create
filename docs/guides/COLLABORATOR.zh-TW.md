## 一句話

這些儲存庫的設計目標是可複製、可執行、可驗證；歡迎貢獻、回報與修正。

## 你想做什麼？

| 我想… | 怎麼做 |
|---|---|
| **貢獻程式碼或文件** | 閱讀[Contribute](../../CONTRIBUTING.zh-TW.md)，並在相應儲存庫中提交 issue 或 PR |
| **回報漏洞** | 請遵循[Security](../../SECURITY.zh-TW.md)；不要在公開 issue 中公布細節 |
| **修正翻譯** | 本檔案及其文件提供 22 種語言，部分翻譯仍可改進；修正尤其有價值 |
| **了解社群規則** | [Code of Conduct](../../CODE_OF_CONDUCT.zh-TW.md) |
| **使用或重用某個儲存庫** | 每個儲存庫都會聲明授權與限制；重用前請先查看 |

## 這些儲存庫如何運作

- 標準化工具：每個儲存庫都有 `Makefile`、`doctor` 與 `smoke`。
- 把資安當作流水線：每次發行都包含密鑰掃描、靜態分析與 SBOM。
- 明確聲明禁止的做法。
- 依受眾撰寫文件：營運、開發或稽核的人都能找到自己的部分。
