## Σε μία γραμμή

Τα αποθετήρια έχουν σχεδιαστεί για να κλωνοποιούνται, να εκτελούνται και να επικυρώνονται· οι συνεισφορές, οι αναφορές και οι διορθώσεις είναι ευπρόσδεκτες.

## Τι θέλετε να κάνετε;

| Θέλω να… | Τι να κάνετε |
|---|---|
| **Συνεισφέρω κώδικα ή τεκμηρίωση** | Διαβάστε [Contribute](../../CONTRIBUTING.el.md) και ανοίξτε issue ή PR στο σχετικό αποθετήριο |
| **Αναφέρω μια ευπάθεια** | Ακολουθήστε [Security](../../SECURITY.el.md)· μη δημοσιεύετε λεπτομέρειες σε ανοικτό issue |
| **Διορθώσω μια μετάφραση** | Αυτό το προφίλ και τα έγγραφά του υπάρχουν σε 22 γλώσσες και ορισμένες μεταφράσεις μπορούν να βελτιωθούν· οι διορθώσεις είναι ιδιαίτερα χρήσιμες |
| **Κατανοήσω τους κανόνες της κοινότητας** | [Code of Conduct](../../CODE_OF_CONDUCT.el.md) |
| **Χρησιμοποιήσω ή επαναχρησιμοποιήσω ένα αποθετήριο** | Κάθε αποθετήριο δηλώνει την άδεια και τα όριά του· ελέγξτε τα πριν το επαναχρησιμοποιήσετε |

## Πώς δουλεύουμε σε αυτά τα αποθετήρια

- Τυποποιημένα εργαλεία: `Makefile`, `doctor` και `smoke` ανά αποθετήριο.
- Ασφάλεια ως pipeline: σάρωση μυστικών, στατική ανάλυση και SBOM ανά έκδοση.
- Οι απαγορευμένες πρακτικές δηλώνονται ρητά.
- Τεκμηρίωση ανά κοινό: όποιος λειτουργεί, αναπτύσσει ή ελέγχει βρίσκει το μέρος του.

## Τι δεν είναι δικό μου έργο

Ο λογαριασμός φυλάσσει [52 forks](../ECOSYSTEM.el.md#forks) έργων τρίτων. Δεν είναι δικό μου έργο: για να συνεισφέρετε, κάντε το στο αρχικό έργο (η στήλη «Αρχικό έργο» παραπέμπει σε καθένα).
