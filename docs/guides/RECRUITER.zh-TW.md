## 一句話

擁有 16 年以上經驗的解決方案架構師與資深全端工程師，受過資訊與電腦工程**以及**企業管理的訓練：串接業務與技術，並以可驗證的證據交付。

## 我是否符合該職缺？

| 如果職缺要求… | 坦率的回答 |
|---|---|
| 解決方案架構師、Tech Lead、資深全端 | ✅ 有據可查的技術資歷（16 年以上） |
| 舊系統現代化（例如 PHP 5.x → 8.x） | ✅ 在不中斷營運的前提下漸進演進 |
| 自動化與 AI（n8n、LangGraph、MCP、附護欄的代理） | ✅ 可以執行的公開產品與實驗室 |
| DevOps、CI/CD、雲端、應用 SRE | ⚙️ 儲存庫中有證據的補充領域；尚無已證實的企業值班經歷 |
| 業務分析、IT 專案管理、產品、售前 | 🔁 可遷移能力或可應徵機會，視範圍而定 |
| 管理或領導（IT 經理、CIO、Head of IT） | 🎯 未來發展目標：團隊、預算與成果仍待證明 |

完整分類（已證實經驗、可遷移能力、可應徵機會、未來目標）見[職位矩陣](../../PROFESIONAL_ROLES.zh-TW.md)與[管理、行政和非編碼職業機會](../MANAGEMENT.zh-TW.md)。

## 5 分鐘內核實

1. 閱讀[可核實狀態](../../README.zh-TW.md#可核實狀態)：附來源的數據。
2. 從[查看完整生態系統](../ECOSYSTEM.zh-TW.md)中開啟一個可安裝的產品，檢查它的發行、校驗碼與測試。
3. 開啟任一儲存庫：每個儲存庫都會說明自身狀態（`可運作`、`已文件化/SCAFFOLD` 或 `規劃中`）以及它**不做**什麼。

## 本檔案不主張的內容

- 自有專案與實驗室**不會**被當作在企業中的工作經歷。
- 未聲明任何專業認證（例如 PMP、CISA、ISO 27001）。
- 在組織內帶領團隊、掌管預算與供應商的經歷尚未證實。
