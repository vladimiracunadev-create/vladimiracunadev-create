## 一句话

这些仓库的设计目标是可克隆、可运行、可验证；欢迎贡献、报告与修正。

## 你想做什么？

| 我想… | 怎么做 |
|---|---|
| **贡献代码或文档** | 阅读[贡献](../../CONTRIBUTING.zh.md)，并在相应仓库中提交 issue 或 PR |
| **报告漏洞** | 请遵循[安全](../../SECURITY.zh.md)；不要在公开 issue 中发布细节 |
| **修正翻译** | 本档案及其文档提供 22 种语言，部分翻译仍可改进；修正尤其有价值 |
| **了解社区规则** | [行为准则](../../CODE_OF_CONDUCT.zh.md) |
| **使用或复用某个仓库** | 每个仓库都会声明许可证与限制；复用前请先查看 |

## 这些仓库如何运作

- 标准化工具：每个仓库都有 `Makefile`、`doctor` 与 `smoke`。
- 把安全当作流水线：每次发布都包含密钥扫描、静态分析与 SBOM。
- 明确声明禁止的做法。
- 按受众编写文档：运维、开发或审计的人都能找到自己的部分。
