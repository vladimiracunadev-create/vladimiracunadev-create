## ในหนึ่งบรรทัด

คลังทั้งหมดออกแบบมาให้โคลน รัน และตรวจสอบได้ ยินดีรับการมีส่วนร่วม รายงาน และการแก้ไข

## คุณต้องการทำอะไร

| ฉันต้องการ… | สิ่งที่ควรทำ |
|---|---|
| **ร่วมสนับสนุนโค้ดหรือเอกสาร** | อ่าน[Contribute](../../CONTRIBUTING.th.md)แล้วเปิด issue หรือ PR ในคลังที่เกี่ยวข้อง |
| **รายงานช่องโหว่** | ทำตาม[Security](../../SECURITY.th.md) อย่าเผยแพร่รายละเอียดใน issue สาธารณะ |
| **แก้ไขคำแปล** | โปรไฟล์นี้และเอกสารมีให้ใน 22 ภาษา และบางคำแปลปรับปรุงได้ การแก้ไขมีประโยชน์เป็นพิเศษ |
| **ทำความเข้าใจกฎของชุมชน** | [Code of Conduct](../../CODE_OF_CONDUCT.th.md) |
| **ใช้หรือนำคลังกลับมาใช้ใหม่** | แต่ละคลังระบุใบอนุญาตและข้อจำกัด โปรดตรวจสอบก่อนนำกลับมาใช้ใหม่ |

## วิธีทำงานในคลังเหล่านี้

- เครื่องมือมาตรฐาน: `Makefile`, `doctor` และ `smoke` ในทุกคลัง
- ความปลอดภัยแบบไปป์ไลน์: การสแกนความลับ การวิเคราะห์แบบสถิต และ SBOM ในทุกรีลีส
- ระบุแนวปฏิบัติที่ห้ามไว้อย่างชัดเจน
- เอกสารตามกลุ่มผู้อ่าน: ผู้ดูแลระบบ ผู้พัฒนา หรือผู้ตรวจสอบ ต่างพบส่วนของตน

## สิ่งที่ไม่ใช่ผลงานของฉันเอง

บัญชีนี้เก็บ[52 forks](../ECOSYSTEM.th.md#forks)ของโปรเจกต์บุคคลที่สาม สิ่งเหล่านี้ไม่ใช่ผลงานของฉันเอง หากต้องการร่วมสนับสนุน ให้ทำที่โปรเจกต์ต้นฉบับ (คอลัมน์ «โปรเจกต์ต้นฉบับ» ลิงก์ไปยังแต่ละโปรเจกต์)
