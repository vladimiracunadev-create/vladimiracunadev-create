## 一言で

リポジトリはクローンし、実行し、検証できるように作られています。貢献、報告、修正を歓迎します。

## 何をしたいですか？

| したいこと | すること |
|---|---|
| **コードやドキュメントで貢献する** | [Contribute](../../CONTRIBUTING.ja.md)を読み、該当リポジトリで issue か PR を作成してください |
| **脆弱性を報告する** | [Security](../../SECURITY.ja.md)に従い、公開 issue には詳細を書かないでください |
| **翻訳を修正する** | このプロフィールとドキュメントは 22 言語で提供されており、改善の余地がある翻訳もあります。修正は特に助かります |
| **コミュニティのルールを知る** | [Code of Conduct](../../CODE_OF_CONDUCT.ja.md) |
| **リポジトリを利用・再利用する** | 各リポジトリがライセンスと制限を明記しています。再利用前にご確認ください |

## これらのリポジトリの進め方

- 標準化されたツール群：リポジトリごとに `Makefile`、`doctor`、`smoke`。
- パイプラインとしてのセキュリティ：リリースごとのシークレットスキャン、静的解析、SBOM。
- 禁止事項を明示。
- 読者別のドキュメント：運用する人、開発する人、監査する人がそれぞれの情報を見つけられます。

## 自作ではないもの

アカウントにはサードパーティプロジェクトの[52 forks](../ECOSYSTEM.ja.md#forks)を保管しています。自作ではありません。貢献する場合は元のプロジェクトで行ってください（「元のプロジェクト」列から各プロジェクトに移動できます）。
