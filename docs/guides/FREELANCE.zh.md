## 我如何工作

1. **先诊断，后干预：**在提出改动之前，先理解系统及其风险。
2. **可复现的交付：**交付物可以被克隆、运行和验证。
3. **可见的质量：**测试、CI 与安全检查是交付的一部分。
4. **按受众编写文档：**运维、决策或开发的人都能找到自己的部分。
5. **如实的状态：**每个部分都声明为可运行、已文档化或计划中。

## 如需报价，请发我一份简短需求说明

- 业务目标，以及成功的标准。
- 技术背景：技术栈、仓库、环境，以及需要审阅的访问权限。
- 约束：期限、参考预算、可用团队、合规要求。
- 已经尝试过什么，以及哪里失败了。
