このプロフィールの技術スタックは、意図の一覧ではなく、このアカウントの公開リポジトリにあるものから成り立っています。本書では、何を証拠とみなすか、各領域がどのリポジトリや場所に基づくか、そして何が筆者の申告にすぎないかを説明します。

## 採用ルール

1. **自分の公開リポジトリのみ。** 非公開リポジトリと第三者プロジェクトのフォークは対象外です。
2. **証拠はリポジトリの中にあります。** コード、マニフェストとロックファイル、Docker/Compose、CI/CD ワークフロー、Terraform、またはラボやカリキュラムの文書に現れるものが対象です。講座の文章での言及だけでは数えません。Snowflake、BigQuery、Spark、Airflow は講座の内容としてのみ登場するため、スタックには含めていません。
3. **年数ではなく使用。** リポジトリに現れることは使用の証拠であり、実務経験の年数を主張するものではありません。
4. **申告は別扱い。** 公開リポジトリから確認できないものは、筆者の申告として区別します（後述）。

## 筆者の申告（公開リポジトリでは確認できないもの）

次の項目は筆者が使っているためスタックに含めていますが、公開リポジトリだけでは単独で証明できません。

- **Cloudflare** — 個人の仕事。
- **ChatGPT Plus**（2023 年から）、**Antigravity**、**OpenCode** — AI 支援開発フローのツール。
- **GitLab に関連する運用中のウェブサイトでの AWS** — 公開で確認できるのはプロジェクト [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab) であり、それらのサイトではありません。

## 確認方法

誰でも GitHub CLI（`gh`）で同じ確認ができます。

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## 維持の方法

- 技術とそのグラフは `scripts/stack_data.json` から `scripts/stack_graphic.py` で生成され、プロフィールの数値は `stats.yml` ワークフローが計算します。
- 技術は公開リポジトリ（コード、マニフェスト、ワークフロー、ラボ）に現れたときスタックに加わり、どこにも現れなくなったときに外れます。

## 限界

- GitHub の言語統計には生成ファイルやデータファイルも含まれます（HTML が大きいのはそのため）。リポジトリに何があるかを示すもので、各言語をどれだけ使いこなせるかを示すものではありません。
- 非公開リポジトリと顧客向けの仕事はこのスタックに含まれず、証拠としても使いません。
