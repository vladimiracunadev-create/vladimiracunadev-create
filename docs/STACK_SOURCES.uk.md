Технологічний стек профілю береться з того, що є в публічних репозиторіях цього облікового запису, а не зі списку намірів. Цей документ пояснює, що вважається доказом, з якого репозиторію чи місця береться кожна ділянка і що є лише заявою автора.

## Правила включення

1. **Лише власні публічні репозиторії.** Приватні репозиторії та форки чужих проєктів не враховуються.
2. **Доказ міститься в репозиторії.** Враховується те, що є в коді, маніфестах і lock-файлах, Docker/Compose, CI/CD-воркфлоу, Terraform або в документації лабораторії чи навчальної програми. Випадкова згадка в тексті курсу не враховується: Snowflake, BigQuery, Spark і Airflow трапляються лише як зміст курсів, тому їх немає в стеку.
3. **Використання, а не роки.** Присутність у репозиторії — свідчення використання, а не твердження про роки виробничого досвіду.
4. **Заявлене окремо.** Те, що не можна перевірити за публічними репозиторіями, позначено як заявлене автором (нижче).

## Заявлено автором (не перевіряється за публічними репозиторіями)

Ці пункти є в стеку, бо автор їх використовує, але жоден публічний репозиторій сам по собі їх не доводить:

- **Cloudflare** — особиста робота.
- **ChatGPT Plus** (з 2023 року), **Antigravity** і **OpenCode** — інструменти процесу розробки за допомогою ШІ.
- **AWS на робочих сайтах, пов'язаних із GitLab** — публічно перевіряється проєкт [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab), а не самі сайти.

## Як перевірити

Будь-хто може повторити перевірку за допомогою GitHub CLI (`gh`):

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## Як це підтримується

- Технології та їхній графік генеруються з `scripts/stack_data.json` скриптом `scripts/stack_graphic.py`; цифри профілю рахує воркфлоу `stats.yml`.
- Технологія потрапляє до стеку, коли з'являється в публічному репозиторії (код, маніфест, воркфлоу чи лабораторія), і вибуває, якщо ніде більше не трапляється.

## Обмеження

- Статистика мов GitHub враховує згенеровані файли та файли даних (тому HTML важить так багато): вона показує, що є в репозиторії, а не наскільки добре я знаю кожну мову.
- Приватні репозиторії та робота для клієнтів не входять до цього стеку й не використовуються як доказ.
