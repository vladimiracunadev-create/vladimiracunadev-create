Stos technologiczny profilu pochodzi z tego, co znajduje się w publicznych repozytoriach tego konta, a nie z listy zamiarów. Ten dokument wyjaśnia, co liczy się jako dowód, z jakiego repozytorium lub miejsca pochodzi każdy obszar i co jest tylko deklaracją autora.

## Zasady włączania

1. **Tylko własne publiczne repozytoria.** Repozytoria prywatne i forki cudzych projektów się nie liczą.
2. **Dowód jest w repozytorium.** Liczy się to, co występuje w kodzie, manifestach i plikach lock, Docker/Compose, workflow CI/CD, Terraform lub w dokumentacji laboratorium albo programu nauczania. Luźna wzmianka w tekście kursu się nie liczy: Snowflake, BigQuery, Spark czy Airflow pojawiają się tylko jako treść kursów, więc nie ma ich w stosie.
3. **Użycie, nie lata.** Obecność w repozytorium to dowód użycia, a nie deklaracja lat doświadczenia produkcyjnego.
4. **To, co zadeklarowane, jest osobno.** Co nie da się sprawdzić w publicznych repozytoriach, jest oznaczone jako deklaracja autora (poniżej).

## Zadeklarowane przez autora (nieweryfikowalne w publicznych repozytoriach)

Te elementy są w stosie, bo autor ich używa, ale żadne publiczne repozytorium nie dowodzi ich samodzielnie:

- **Cloudflare** — praca osobista.
- **ChatGPT Plus** (od 2023), **Antigravity** i **OpenCode** — narzędzia przepływu pracy wspomaganego AI.
- **AWS w działających stronach powiązanych z GitLab** — publicznie weryfikowalny jest projekt [proyectos-aws-gitlab](https://gitlab.com/vladimir.acuna.dev-group/proyectos-aws-gitlab), a nie te strony.

## Jak to sprawdzić

Każdy może powtórzyć weryfikację za pomocą GitHub CLI (`gh`):

```bash
gh repo list vladimiracunadev-create --visibility public --source --limit 200
gh api repos/vladimiracunadev-create/<repo>/languages
gh search code "<tech>" --owner vladimiracunadev-create
```

## Jak jest utrzymywany

- Technologie i ich grafika są generowane z `scripts/stack_data.json` przez `scripts/stack_graphic.py`; liczby profilu oblicza workflow `stats.yml`.
- Technologia trafia do stosu, gdy pojawia się w publicznym repozytorium (kod, manifest, workflow lub laboratorium), i odpada, gdy przestaje się pojawiać w jakimkolwiek.

## Ograniczenia

- Statystyki języków GitHub liczą pliki generowane i danych (dlatego HTML tak waży): pokazują, co zawiera repozytorium, a nie jak dobrze znam każdy język.
- Repozytoria prywatne i praca dla klientów nie należą do tego stosu i nie służą jako dowód.
